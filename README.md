# Mountain-Flood-UAV-Scheduling

Supplementary materials for the paper:

**Joint Scheduling of UAV Cargo Delivery and Communication Relay for Mountain Flood Disaster Response: A Case Study**

## Overview

This repository provides supplementary materials for the sensitivity and robustness analysis reported in the paper.

The supplementary experiments examine three practical factors:

- Relief-demand scale: 60, 80, 100, and 120 relief boxes
- Number of available relay UAVs: 1, 2, 3, and 4
- Terrain-relief scaling factor: 0.8, 1.0, and 1.2

## Feasibility criterion

A joint transport-relay solution is regarded as feasible only when:

- the number of hard delivery-deadline violations is zero; and
- the number of communication-outage samples is zero.

## Contents

This repository will contain:

- detailed sensitivity-analysis settings;
- numerical results and tables;
- sensitivity figures;
- MATLAB scripts used for the experiments;
- supplementary discussion of robustness and practical uncertainties.
